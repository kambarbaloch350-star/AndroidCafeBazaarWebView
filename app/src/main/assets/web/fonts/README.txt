# fonts/

`vazirmatn-variable.woff2` is the OFL-licensed **Vazirmatn** variable font
(weights 100–900) used by the WebApp skeleton for Persian/RTL typography.

`vazirmatn-local.css` declares the `@font-face` rule. Because the font ships
inside the APK (served by the embedded HTTP server), the WebApp never performs
a CDN request — first paint is instant and fully offline-capable.

Source: https://github.com/rastikerdar/vazirmatn (SIL Open Font License 1.1)
